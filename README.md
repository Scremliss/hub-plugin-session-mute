# session-mute — мьют сессий для Agents Hub

Плагин страницы хаба: колокольчик у строки любой сессии (специалиста, направления, исполнителя, самого хаба) и в шапке
открытой сессии. Заглушённая — как канал в Telegram: у неё нет синей точки «новое», подсказки «ответ?» и места в разделе
«Новое», имя серое, значок колокольчика с чертой виден всегда.

**Вопросы и запросы разрешения не глушатся:** красная метка и «Ждут вас» остаются, чтобы не пропустить то, что стоит без вас.

## Как поставить

В Agents Hub: «Настройки» → «Плагины» → «Найти» → `session-mute`.
Или хабу: «поставь плагин `Scremliss/hub-plugin-session-mute`» (`hub market install Scremliss/hub-plugin-session-mute`).
Выключить — там же, в «Плагинах»; список заглушённых при этом остаётся в браузере.

## Что внутри

Только `main.js`: через `hub.addUnread` гасит «новое» у заглушённых, через `hub.addSlot` рисует колокольчик
(`sidebar.session` и `session.header`) и пишет список имён в `localStorage` браузера (`hub.mutedSessions`). В сеть ничего
не отправляет, ядро не вызывает. Нужен Plugin API хаба 1.25 и новее.

## Ограничения

- Список хранится в браузере: на телефоне и в другом браузере он свой.
- Пункта в меню правого щелчка нет (плагины не могут его дополнять) — только колокольчик.
- «Ответ?» гасится правкой строки сессии в `addUnread` — если хаб изменит этот объект, понадобится обновить плагин.
